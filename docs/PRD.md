# 任务安排与项目管理工作台 — 产品需求文档（PRD）

| 项目 | 说明 |
|------|------|
| 产品名称 | 任务安排工作台（Personal Task Workbench） |
| 版本 | v1.0 |
| 文档状态 | 初稿 |
| 目标用户 | 个人知识工作者 / 项目协作者（先做个人侧） |
| 技术栈 | Vue 3 + TypeScript + Pinia + Vue Router + Vite |

---

## 1. 背景与问题

事情一多就容易乱：老板临时安排、客户待回复、今日交付、等人反馈……全部混在一起。常见痛点：

- **靠脑子记事**：忙了一整天仍担心遗漏。
- **信息分散**：任务、会议、项目进度散落在聊天/表格/日历里。
- **优先级不清**：不知道今天先做什么、明天先处理什么。
- **冲突难发现**：时间重叠、逾期事项不能及时看见。
- **变更无迹**：任务时间/负责人调整后，说不清为何改、改成了什么。

本产品把零散工作集中到一个工作台，按优先级与时间安排处理，减少「用脑子当待办本」。

---

## 2. 产品目标

### 2.1 核心目标

1. **一眼看清今日**：打开即知今日待办、进行中、逾期与时间冲突。
2. **日程可视化**：按周查看任务分布，会议 / 交付 / 沟通一目了然。
3. **任务可追踪**：负责人、截止时间、优先级、状态完整记录。
4. **项目有进度**：各项目做到哪一步、还剩多少未完成。
5. **分类可筛选**：用标签管理客户、紧急、会议、跟进等场景。
6. **智能提醒**：逾期、即将到期、时间冲突集中查看。
7. **变更可回溯**：时间/负责人等调整留下历史记录。

### 2.2 非目标（v1 不做）

- 多人实时协作编辑、权限体系
- 与第三方日历 / IM / 邮件深度双向同步
- 移动端原生 App
- AI 自动排期 / 自动写任务（可后续迭代）

## 5. 功能需求

### 5.1 工作总览（P0）

工作台首页，聚合关键信息。

| 模块 | 说明 | 优先级 |
|------|------|--------|
| 统计卡片 | 今日待办、进行中、逾期待办、时间冲突；支持环比提示（如较昨日 +2） | P0 |
| 周日程安排 | 周一～周日，时间轴约 08:00–18:00；任务以色块展示标题/时间/负责人；冲突块高亮 | P0 |
| 小日历 | 月视图，高亮今日；点击日期联动「今日时间线 / 日程清单」 | P0 |
| 今日时间线 | 当日任务按时间纵向排列，展示状态标签 | P0 |
| 日程清单 | 当日（或所选日）任务表：# / 标题 / 项目 / 负责人 / 截止 / 状态 | P0 |
| 待处理提醒 | 临期预警、跟进事项、协作相关等进度/占比展示 | P0 |
| 标签分类 | 标签云/徽章 + 数量，可点击跳转筛选 | P0 |
| 最近调整记录 | 时间、任务名、调整内容、原值、新值、原因 | P0 |

### 5.2 今日任务 / 任务管理（P0）

- 任务字段：标题、描述（备注）、所属项目、父级任务（可选，支持多级拆分细化）、负责人、对接人、开始/截止时间、优先级、状态、标签、是否全天。
- 状态枚举：`待处理` | `进行中` | `待确认` | `已完成` | `已取消`。
- 优先级：`低` | `中` | `高` | `紧急`。
- 支持筛选（状态/项目/标签/负责人/日期）、搜索、新建/编辑/完成。
- 任务编辑：列表行「编辑」回填表单，逐字段比对后仅变更字段写入历史记录（含备注、对接人、标签增删）。
- 备注展示：任务列表标题下方灰色小字（最多两行）；周视图悬浮卡与重叠列表面板同步展示。
- 「今日任务」视图：截止日或计划日为今天，或状态为进行中且落在今日时段。
- 全局关联跳转（各界面数据联动）：
  - 任务管理支持 URL 参数 `?task=<id>` 直达，打开页面即展开该任务的详情抽屉；关闭抽屉/转编辑时自动移除参数，刷新页面可恢复展开状态；指向已删除任务时提示「未找到对应的任务」并清除参数。
  - 工作总览（今日时间线、日程清单、最近调整记录）、甘特图任务名、周视图重叠簇面板、提醒页（逾期任务表、时间重叠列表）、历史记录页的任务名均为链接，点击跳转任务管理并展开对应任务详情。
  - 项目名（总览时间线/日程清单、详情抽屉、项目管理卡片标题）为链接，点击跳转任务管理并按该项目筛选；详情抽屉中的标签也可点击跳转按标签筛选。
  - 任务列表内点击标题即展开详情抽屉；点击项目列/标签徽章在当前页按该项切换筛选。

### 5.3 日程安排（P0）

- 总览保留周视图（概览定位）；独立日程页为甘特图：每行一个任务，横向跨天条、纵向时刻分布、今天列高亮、当前时刻红竖线、悬浮信息卡。
- 日程页头部为三张独立卡片横向等高排列：「日程安排（如何阅读）」「颜色标识与注意事项」「小日历」；小日历列宽约为原等宽布局的 2/3（最小 260px），窄屏（≤1200px）回落为单列堆叠。
- 支持切换上一周 / 下一周 / 回到今天（与周视图共用周导航状态）。
- 时间冲突检测：同一负责人（个人场景即自己）在重叠时间段存在 ≥2 个非取消任务 → 标记冲突。

### 5.4 项目管理（P0）

- 项目字段：名称、描述、状态（进行中/已归档）、进度百分比、关联任务数、未完成数。
- 列表/卡片展示进度条；点击进入该项目下任务列表。

### 5.5 标签分类（P1）

- 预置标签示例：客户相关、重要紧急、会议相关、产品需求、文档整理、后续跟进。
- 支持自定义标签名与颜色；展示各标签任务计数；点击进入筛选结果。

### 5.6 智能提醒 / 冲突与提醒（P0）

| 提醒类型 | 规则（v1） |
|----------|------------|
| 逾期待办 | 截止时间 < 当前时间，且状态 ≠ 已完成/已取消 |
| 即将到期 | 截止在未来 N 小时内（默认 24h），未完成 |
| 时间冲突 | 日程时间段重叠（警告级提醒：任务支持并行，重叠仅提示留意安排） |
| 待跟进 | 带「后续跟进」类标签或状态为待确认 |

侧边栏角标 = 未读/未处理提醒数量（冲突 + 逾期等可配置）。

### 5.7 历史记录（P1）

任务发生以下变更时写入审计日志：

- 时间调整、负责人变更、状态变更、优先级变更、项目归属变更等。

字段：时间、任务名、调整内容、原值、新值、原因（可选）。

v1 可用本地 mock / localStorage；后续接后端。

### 5.8 系统设置（P2）

- 个人资料展示（显示名称，顶栏头像同步）、工作日时间范围（默认 08:00–18:00，驱动甘特/周视图时间轴）、临期提醒窗口（1–72h，驱动临期提醒）。
- 偏好项保存到 localStorage（独立 key），保存按钮 + 未保存修改提示 + 校验（结束时间须晚于开始）。
- v1 可先做静态设置页 + 本地偏好。

### 5.9 全局搜索（P1）

顶栏搜索：任务标题、项目名、标签、负责人；回车或选择结果跳转对应详情/列表。

### 5.10 工作报告（P1，已交付一期）

日报 / 周报 / 月报自动汇总，基于任务与历史留痕，纯前端模板化生成（零 AI 依赖）。

- 数据口径：
  - 完成 = 历史留痕中「状态变更 → 已完成」动作（当日发生即计入，含完成后重开的重做）；不含已取消任务。
  - 新增 = 历史留痕「新建任务」记录。
  - 时间投入 = 计划口径（startAt→endAt），非实际耗时。
  - 逾期 = 截止早于周期末日且未完成（未来周期以今天为界）。
  - 完成 = completedAt 归因优先（含闭环补录），历史留痕反推兜底（见 5.11）。
- 日报：今日完成 / 进行中 / 今日新增 / 明日排期 / 逾期未完成 / 当日调整记录。
- 周报：本周概览（完成/进行中/新建/逾期计数）/ 完成明细 / 项目进展 / 时间投入（按项目，含占比）/ 未完成与风险（逾期+高优先级）/ 下周排期。
- 月报：月度概览 / 周完成趋势（月内 1–7、8–14… 分段柱状）/ 项目进展 / 完成任务标签分布 / 完成明细。
- 交互：期间导航（‹ › / 今天 / 本周 / 本月）；「视图 / Markdown」双模式；一键复制 Markdown（可粘贴到日报表或文档归档）；报告内任务名均为链接，点击跳任务详情抽屉。
- 实现位置：`src/utils/report.ts`（纯函数数据层 + Markdown 序列化）+ `src/views/ReportView.vue`（/report）。

**二期计划（AI 总结润色）**：设置页增加可选「AI 增强」配置（OpenAI 兼容端点 + 模型名，默认指向本机 llama.cpp），报告页提供「AI 润色」按钮，将前端已算好的统计数据作为上下文生成自然语言叙述；未配置时功能完整可用、按钮不展示；默认本地端点保证任务数据不出本机。

### 5.11 报告闭环检查（P1，已交付）

进入报告页自动检测「计划时间与任务状态不一致」的任务并弹导向导（每会话一次），横幅常驻提供手动入口；确认结果实时反映到报告。已延期任务不重复追问；已取消任务跳过。

| 用例 | 场景 | 分组 | 确认选项与动作 |
|------|------|------|------|
| CL-C1/C2 | 计划窗口已过、未完成（待处理/待确认/进行中） | 必答 | ① 已完成 → 补录完成日期（默认今天）+ 状态完成；② 进行中 → 进展说明（已进行中的仅追加进展）；③ 未开始 → 标识延期（仅打标 + 说明，不改计划时间） |
| CL-B1 | 窗口内、未标记开始（待处理/待确认） | 必答 | 同 C 组三选（①按"其实已完成"语义） |
| CL-B2 | 窗口内、进行中 | 可选采集 | 已完成（补录日期）/ 记录进展说明 / 跳过 |
| CL-A2 | 未到计划开始却标记进行中/待确认 | 必答 | 保留（确认提前开工）/ 改回待处理 |
| CL-A3 | 计划开始前已完成（提前完成） | 无需确认 | 归因 completedAt 日；计划日排期显示"✓ 已提前完成（实际 M/D）"；下周排期同样标记 |
| CL-C3/C4 | 已完成（超时/无完成时间） | 自动 | 超时（completedAt > endAt）进月报时效统计；无 completedAt 的旧数据加载时从历史留痕自动反推 |

- 数据模型：Task 增加 `completedAt`（完成时间，done 必有，重开自动清空）、`delayed` / `delayNote`（延期标识）。完成态切换由 store 自动维护 completedAt；完成重置 delayed。
- 归因口径：报告完成归因 = completedAt 优先（含闭环补录），历史留痕反推兜底；进展说明写入历史记录（字段=进展说明），周报"进行中与进展"、日报进行中、抽屉"最近进展"均展示最近一条。
- 报告展示：周报 KPI 增加"已确认延期"，风险节含逾期/延期/高优先级三组；月报概览含完成时效（提前/按时/超时）；延期任务在任务列表与详情抽屉显示红色"延期"徽章与说明。
- 实现位置：闭环保守函数 `closedLoopChecks` 于 `src/utils/report.ts`；向导组件 `src/components/common/ClosedLoopWizard.vue`；动作（completeTask/markStarted/markDelayed/addProgressNote/confirmEarlyStart）于 store。

## 6. 数据模型（v1）

### 6.1 Task

```ts
{
  id: string
  title: string
  description?: string
  projectId?: string
  parentId?: string   // 父级任务 id（支持多级拆分：任意任务可继续拆分子任务；子任务可解除关联成为独立任务；不允许挂到自身后代下形成环）
  owner: string
  contact?: string  // 对接人（客户/协作方联系人）
  startAt: string   // ISO
  endAt: string     // ISO
  deadline?: string // ISO
  priority: 'low' | 'medium' | 'high' | 'urgent'
  status: 'pending' | 'in_progress' | 'to_confirm' | 'delayed' | 'done' | 'cancelled'  // delayed 为 FIX-6 扩展（延期处理）
  tagIds: string[]
  createdAt: string
  updatedAt: string
}
```

### 6.2 Project

```ts
{
  id: string
  name: string
  description?: string
  status: 'active' | 'archived'
  progress: number // 0-100，可由任务完成率派生或手工维护
}
```

### 6.3 Tag

```ts
{
  id: string
  name: string
  color: string
}
```

### 6.4 Reminder / Conflict（可由任务派生）

```ts
{
  id: string
  type: 'overdue' | 'due_soon' | 'conflict' | 'follow_up'
  taskIds: string[]
  title: string
  severity: 'info' | 'warning' | 'danger'
}
```

### 6.5 HistoryRecord

```ts
{
  id: string
  time: string
  taskId: string
  taskTitle: string
  field: string        // 如「时间调整」
  oldValue: string
  newValue: string
  reason?: string
}
```

## 7. 页面与交互规格

### 7.1 工作总览

- 进入 `/` 即展示上述模块；数据来自统一 store。
- 周日程块点击 → 展开重叠簇列表面板，点击面板条目跳转任务管理并展开任务详情（URL `?task=<id>`，抽屉带展开动画）。
- 周/甘特色块按状态着色（见 7.2）；冲突块橙色高亮，已完成块灰度弱化。
- 小日历选中日 → 刷新时间线与日程清单。

### 7.2 状态视觉

| 状态 | 色值（周视图色块 / 甘特图条形） | 徽章 |
|------|------|------|
| 待处理 | 蓝 `#3b82f6` | 蓝底徽章 |
| 进行中 | 绿 `#10b981` | 绿底徽章 |
| 待确认 | 紫 `#8b5cf6` | 紫底徽章（BK-1 统一） |
| 已完成 | 灰 `#94a3b8`（整块灰度弱化） | 灰底徽章 |

主色参考设计稿：侧栏深色；内容区浅灰底；强调色可用柔和绿色或蓝色（实现以设计稿第二版浅绿为主，冲突/逾期保留警示红）。
