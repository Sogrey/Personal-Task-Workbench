# 任务安排与项目管理工作台 — 产品需求文档（PRD）

| 项目 | 说明 |
|------|------|
| 产品名称 | 任务安排工作台（Personal Task Workbench） |
| 版本 | v1.0 |
| 文档状态 | 初稿 |
| 目标用户 | 个人知识工作者 / 项目协作者（先做个人侧） |
| 技术栈 | Vue 3 + TypeScript + Pinia + Vue Router + Vite |

---

## 1. 背景与问题

事情一多就容易乱：老板临时安排、客户待回复、今日交付、等人反馈……全部混在一起。常见痛点：

- **靠脑子记事**：忙了一整天仍担心遗漏。
- **信息分散**：任务、会议、项目进度散落在聊天/表格/日历里。
- **优先级不清**：不知道今天先做什么、明天先处理什么。
- **冲突难发现**：时间重叠、逾期事项不能及时看见。
- **变更无迹**：任务时间/负责人调整后，说不清为何改、改成了什么。

本产品把零散工作集中到一个工作台，按优先级与时间安排处理，减少「用脑子当待办本」。

---

## 2. 产品目标

### 2.1 核心目标

1. **一眼看清今日**：打开即知今日待办、进行中、逾期与时间冲突。
2. **日程可视化**：按周查看任务分布，会议 / 交付 / 沟通一目了然。
3. **任务可追踪**：负责人、截止时间、优先级、状态完整记录。
4. **项目有进度**：各项目做到哪一步、还剩多少未完成。
5. **分类可筛选**：用标签管理客户、紧急、会议、跟进等场景。
6. **智能提醒**：逾期、即将到期、时间冲突集中查看。
7. **变更可回溯**：时间/负责人等调整留下历史记录。

### 2.2 非目标（v1 不做）

- 多人实时协作编辑、权限体系
- 与第三方日历 / IM / 邮件深度双向同步
- 移动端原生 App
- AI 自动排期 / 自动写任务（可后续迭代）

## 5. 功能需求

### 5.1 工作总览（P0）

工作台首页，聚合关键信息。

| 模块 | 说明 | 优先级 |
|------|------|--------|
| 统计卡片 | 今日待办、进行中、逾期待办、时间冲突；支持环比提示（如较昨日 +2） | P0 |
| 周日程安排 | 周一～周日，时间轴约 08:00–18:00；任务以色块展示标题/时间/负责人；冲突块高亮 | P0 |
| 小日历 | 月视图，高亮今日；点击日期联动「今日时间线 / 日程清单」 | P0 |
| 今日时间线 | 当日任务按时间纵向排列，展示状态标签 | P0 |
| 日程清单 | 当日（或所选日）任务表：# / 标题 / 项目 / 负责人 / 截止 / 状态 | P0 |
| 待处理提醒 | 临期预警、跟进事项、协作相关等进度/占比展示 | P0 |
| 标签分类 | 标签云/徽章 + 数量，可点击跳转筛选 | P0 |
| 最近调整记录 | 时间、任务名、调整内容、原值、新值、原因 | P0 |

### 5.2 今日任务 / 任务管理（P0）

- 任务字段：标题、描述（备注）、所属项目、负责人、对接人、开始/截止时间、优先级、状态、标签、是否全天。
- 状态枚举：`待处理` | `进行中` | `待确认` | `已完成` | `已取消`。
- 优先级：`低` | `中` | `高` | `紧急`。
- 支持筛选（状态/项目/标签/负责人/日期）、搜索、新建/编辑/完成。
- 任务编辑：列表行「编辑」回填表单，逐字段比对后仅变更字段写入历史记录（含备注、对接人、标签增删）。
- 备注展示：任务列表标题下方灰色小字（最多两行）；周视图悬浮卡与重叠列表面板同步展示。
- 「今日任务」视图：截止日或计划日为今天，或状态为进行中且落在今日时段。

### 5.3 日程安排（P0）

- 总览保留周视图（概览定位）；独立日程页为甘特图：每行一个任务，横向跨天条、纵向时刻分布、今天列高亮、当前时刻红竖线、悬浮信息卡。
- 日程页头部为三张独立卡片横向等高排列：「日程安排（如何阅读）」「颜色标识与注意事项」「小日历」；窄屏（≤1200px）回落为单列堆叠。
- 支持切换上一周 / 下一周 / 回到今天（与周视图共用周导航状态）。
- 时间冲突检测：同一负责人（个人场景即自己）在重叠时间段存在 ≥2 个非取消任务 → 标记冲突。

### 5.4 项目管理（P0）

- 项目字段：名称、描述、状态（进行中/已归档）、进度百分比、关联任务数、未完成数。
- 列表/卡片展示进度条；点击进入该项目下任务列表。

### 5.5 标签分类（P1）

- 预置标签示例：客户相关、重要紧急、会议相关、产品需求、文档整理、后续跟进。
- 支持自定义标签名与颜色；展示各标签任务计数；点击进入筛选结果。

### 5.6 智能提醒 / 冲突与提醒（P0）

| 提醒类型 | 规则（v1） |
|----------|------------|
| 逾期待办 | 截止时间 < 当前时间，且状态 ≠ 已完成/已取消 |
| 即将到期 | 截止在未来 N 小时内（默认 24h），未完成 |
| 时间冲突 | 日程时间段重叠（警告级提醒：任务支持并行，重叠仅提示留意安排） |
| 待跟进 | 带「后续跟进」类标签或状态为待确认 |

侧边栏角标 = 未读/未处理提醒数量（冲突 + 逾期等可配置）。

### 5.7 历史记录（P1）

任务发生以下变更时写入审计日志：

- 时间调整、负责人变更、状态变更、优先级变更、项目归属变更等。

字段：时间、任务名、调整内容、原值、新值、原因（可选）。

v1 可用本地 mock / localStorage；后续接后端。

### 5.8 系统设置（P2）

- 个人资料展示（显示名称，顶栏头像同步）、工作日时间范围（默认 08:00–18:00，驱动甘特/周视图时间轴）、临期提醒窗口（1–72h，驱动临期提醒）。
- 偏好项保存到 localStorage（独立 key），保存按钮 + 未保存修改提示 + 校验（结束时间须晚于开始）。
- v1 可先做静态设置页 + 本地偏好。

### 5.9 全局搜索（P1）

顶栏搜索：任务标题、项目名、标签、负责人；回车或选择结果跳转对应详情/列表。

## 6. 数据模型（v1）

### 6.1 Task

```ts
{
  id: string
  title: string
  description?: string
  projectId?: string
  owner: string
  contact?: string  // 对接人（客户/协作方联系人）
  startAt: string   // ISO
  endAt: string     // ISO
  deadline?: string // ISO
  priority: 'low' | 'medium' | 'high' | 'urgent'
  status: 'pending' | 'in_progress' | 'to_confirm' | 'done' | 'cancelled'
  tagIds: string[]
  createdAt: string
  updatedAt: string
}
```

### 6.2 Project

```ts
{
  id: string
  name: string
  description?: string
  status: 'active' | 'archived'
  progress: number // 0-100，可由任务完成率派生或手工维护
}
```

### 6.3 Tag

```ts
{
  id: string
  name: string
  color: string
}
```

### 6.4 Reminder / Conflict（可由任务派生）

```ts
{
  id: string
  type: 'overdue' | 'due_soon' | 'conflict' | 'follow_up'
  taskIds: string[]
  title: string
  severity: 'info' | 'warning' | 'danger'
}
```

### 6.5 HistoryRecord

```ts
{
  id: string
  time: string
  taskId: string
  taskTitle: string
  field: string        // 如「时间调整」
  oldValue: string
  newValue: string
  reason?: string
}
```

## 7. 页面与交互规格

### 7.1 工作总览

- 进入 `/` 即展示上述模块；数据来自统一 store。
- 周日程块点击 → 打开任务详情（抽屉或弹层，v1 可跳转任务管理并高亮）。
- 冲突任务在周视图中用红色描边/浅红底区分。
- 小日历选中日 → 刷新时间线与日程清单。

### 7.2 状态视觉

| 状态 | 建议色 |
|------|--------|
| 进行中 | 绿 |
| 待处理 | 蓝 |
| 待确认 | 橙 |
| 已完成 | 灰/绿勾 |
| 逾期 | 红（错误级） |
| 时间冲突 | 橙（警告级，任务可并行） |

主色参考设计稿：侧栏深色；内容区浅灰底；强调色可用柔和绿色或蓝色（实现以设计稿第二版浅绿为主，冲突/逾期保留警示红）。

| 类型 | 要求 |

## 10. 验收标准（v1 原型）

1. 侧边栏 8 个入口可路由切换，当前项高亮；冲突入口有数量角标。
2. 工作总览展示：4 张统计卡、周日程、小日历、今日时间线、日程清单、提醒、标签、调整记录。
3. 周日程能看到多日任务色块，冲突任务有明显样式。
4. 任务管理页可查看列表并按状态筛选；支持基本新增/改状态（本地）。
5. 项目页展示进度与未完成数。
6. 提醒页集中列出逾期与冲突。
7. 历史页展示调整记录表格。
8. 清除脚手架示例页与无用资产；`npm run dev` 可正常启动。

## 12. 风险与后续

- **纯前端 mock**：刷新策略与持久化需约定（建议 localStorage）。
- **冲突算法**：仅按时间重叠；后续可按会议室/参与人扩展。
- **个性化**：真正有用的工作台会随习惯迭代——PRD 允许按使用反馈调整模块优先级。
