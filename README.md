# 任务安排工作台

个人任务安排与项目管理工作台（Vue 3 + TypeScript + Pinia + Vue Router）。

把今日任务、周日程、项目进度、标签分类、冲突提醒与调整历史集中到一个地方管理。

## 快速开始

```sh
npm install
npm run dev
```

## 文档

- 产品需求：[docs/PRD.md](./docs/PRD.md)

## 脚本

| 命令 | 说明 |
|------|------|
| `npm run dev` | 本地开发 |
| `npm run build` | 类型检查 + 构建 |
| `npm run preview` | 预览构建产物 |
